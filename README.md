# PLDeb.github.io

Site hébergé via GitHub Pages.

## Contenu

- `index.html` — Veelution, studio de lancement (image de marque, sites web, accompagnement)
- `assets/` — images du site (logo, photos de projets)
- `app.html` / `agri.html` — application de gestion agri-affaires
- `.nojekyll` — désactive le traitement Jekyll de GitHub Pages
